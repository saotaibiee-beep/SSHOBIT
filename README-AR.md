# SSHOBIT — وثائق المشروع

المشروع مستقل تماماً عن SSHO STORE.

- اللغة الأساسية: العربية باللهجة السعودية البيضاء.
- السوق الأول: المملكة العربية السعودية.
- الواجهة: Next.js 15 + React 19 + TypeScript.
- قاعدة البيانات: Supabase مستقل مخصص لـ SSHOBIT.
- الاستضافة: Vercel.

## تشغيل محلي
`npm install`
`cp .env.example .env.local`
`npm run dev`

## متغيرات البيئة
`NEXT_PUBLIC_SITE_URL`
`NEXT_PUBLIC_SUPABASE_URL`
`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

لا تضف service role key إلى المتصفح أو متغيرات NEXT_PUBLIC_. لا تعرض الدفع قبل بناء التحقق الخادمي من webhooks.

## حالة التنفيذ
الواجهة الأساسية والتشخيص الإرشادي وصفحات التأسيس وSEO الأولي أضيفت. قاعدة البيانات أُنشئت في مشروع Supabase مستقل. يلزم استكمال لوحة الإدارة وتسجيل الدخول ومحتوى المصادر والدفع والاختبارات والنشر النهائي. صفحات الخصوصية والشروط تحتاج مراجعة قانونية وبيانات المشغل.
